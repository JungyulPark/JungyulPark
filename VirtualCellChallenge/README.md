# VirtualCellChallenge — 역량 검증 & credibility (土)

> 통합 미션 中 **"검증"** 축. Arc Institute Virtual Cell Challenge 참가로 모델링 역량을 외부 벤치마크로 증명한다.
> 전략 맥락: `../00_STRATEGY/2026_focus_plan.md`.

## 왜 참가하나 (메인과의 연결)
- **목적지가 아니라 수단.** 챌린지 우승이 목표가 아니라, `VirtualCell_TGFb1` 레이어를 만드는 역량을 **공개 벤치마크로 검증**하고 academic credibility(土)를 적립하는 것.
- Arc STATE·평가지표(PDS)를 익히면 → 그대로 우리 질환특화 레이어 인프라가 된다.

## Arc Virtual Cell Challenge 개요
- 세포 perturbation 반응 예측 공개·반복 벤치마크 대회 ("virtual cell의 튜링 테스트", Cell 2025).
- 평가: **PDS** (예측 상태가 정답 perturbation 상태에 가장 가까운가).
- 베이스라인 모델: **STATE** (SE + ST), 코드 오픈.

## 실행 계획 (2026 Q4 목표)
- [ ] 대회 현재 라운드·마감·데이터셋 확인
- [ ] STATE 베이스라인 재현 (PDS 측정)
- [ ] 개선 시도 1개 (질환특화 fine-tune 아이디어 연결)
- [ ] 제출 + 결과를 `VirtualCell_TGFb1` 레이어로 환류

## 주의
- 챌린지에 **본업 시간을 과투입하지 않는다.** credibility 적립 + 인프라 학습 선까지만. (식상 과잉·분산 경계)
